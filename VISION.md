# Vision

We want to create a persistent cooperative world where players can explore, build, hunt, trade, cooperate and create history.

The world should feel beautiful, dangerous and indifferent.

Nature is not an enemy.

Nature simply does not care if the player survives.

Player choices can create consequences later.

A tree cut today may matter years later.

A river changed today may affect a future settlement.

A clan can prosper, decline, disappear or be rebuilt by another generation of players.

The world should accumulate history instead of constantly resetting.

Realism should create meaningful situations.

Realism should never become repetitive work.

The game should remain enjoyable first.
