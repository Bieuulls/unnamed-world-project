# Concept Art Policy

Concept art in this repository exists to communicate the intended mood, world, characters and design direction while the playable prototype is still being built.

Current public concept images are stored in `assets/concept/`.

Unless explicitly labeled otherwise, current concept images are AI-assisted and must never be presented as in-game screenshots.

Future public media should use clear labels such as:

- `CONCEPT ART - AI ASSISTED`
- `PROTOTYPE`
- `IN-GAME`
- `MOCKUP`

Third-party copyrighted reference images must not be copied into the public repository without permission.
