# Initial Roadmap

## Phase 0 — Foundation

- choose project name
- define world
- define Book Zero
- define visual direction
- define core gameplay
- prepare first prototype

## Phase 1 — World Prototype

Create one small but beautiful playable region containing:

- forest
- river
- terrain
- wildlife
- player character
- gathering
- tree cutting
- basic building

## Phase 2 — Living World Test

Add:

- tree regeneration
- basic wildlife population behavior
- environmental consequences
- simple resource recovery

## Phase 3 — Cooperative Test

Add:

- 2 to 5 players
- shared construction
- shared resource gathering
- cooperative exploration

Do not add release dates.

Do not promise future systems.
